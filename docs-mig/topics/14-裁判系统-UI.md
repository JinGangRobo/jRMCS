### 1.2 关键事实

- `dual_infantry.cpp` / `dual_sentry.cpp` / `mini_infantry.cpp` 三者**除类名外完全一致**
  （`diff` 仅差 `dual_infantry.cpp:15` 多一行未使用的 `#include <utility/angle_warper.hpp>`）。
  它们共享同一套「四向底盘指示 + 受击方向 + StatusRing + StatusBar」逻辑。
- v2 各机型 config **都显式接线**了对应的 `app::ui::*` 组件：
  - `dual-infantry.yaml:12 → app::ui::DualInfantry -> dual_infantry_ui`
  - `dual-sentry.yaml:12 → app::ui::DualSentry -> dual_sentry`
  - `mini-infantry.yaml:12 → app::ui::MiniInfantry -> referee_ui_mini_infantry`
  - `mec-hero.yaml:15 → app::ui::Hero -> referee_ui_hero`
- UI 组件本身**不注册 output**；它只驱动 `Shape` 子类，`Shape` 通过全局 `CfsScheduler<Shape>` 自注册，
  再由 `command/interaction/ui.cpp`（`Ui`）打包发送。故「哪个 UI 组件被实例化」由 config 决定。

### 1.3 双板兵（dual_*）UI 的能力要点

- `StatusRing`：超级电容、功率安全、摩擦轮、弹速；
- `StatusBar`：功率/冷却/弹丸/中心区状态；
- 四向 `Arc` 底盘方向指示（`ChassisMode` 着色）；
- **受击方向指示**：依赖 `/referee/robot/hurt` + `/tf`，用
  `fast_tf::lookup_transform<GimbalCenterLink, OdomImu>` 与 `<OdomImu, YawLink>` 把装甲受击方向
  折算到底盘 yaw（`dual_infantry.cpp:175–210`）。
