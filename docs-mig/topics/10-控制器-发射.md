## 0. 本次核对的结论摘要

1. **17mm 拨弹**有实质差异：v3 换成 `/auto_aim/should_shoot` + `/auto_aim/single_shoot`（v2 为 `/gimbal/auto_aim/shoot_permit`）、**移除 `keyboard.f` 手动单发**、**新增热量接口缺失兜底** `bullet_allowance_default`、并改写触发逻辑（v2 的 `mouse.left || switch_left==DOWN || (switch_right==UP && fire_control)` → v3 的 `aiming_enable ? should_shoot : attack_intent`）。
2. **42mm 拨弹**是**双向分叉**：v3 有可用的 `low_latency_mode`（Ctrl+R 切换）+ `COMPRESSING/COMPRESSED` 阶段（v2 只声明了成员从不赋值）；而 v2 有**电机离线门控**（`/gimbal/bullet_feeder/alive`）、`/debug/*` 输出、`velocity_filtered` 输入，且**标定常数与 PID 增益完全不同**（`compressed_zero_point` 1.05 vs 0.58；`angle_per_bullet` `2π/5` vs `2π/6`）。两者不能简单互相覆盖。
3. **摩擦轮**：v3 删除 `/chassis/operate_mode` 耦合与「摩擦轮电机离线门控」，新增 `/working_velocity` 输出（供 UI）。
4. **heat**：v3 **删除 `/gimbal/shooter/heat` 输出**（v2 有）。
5. **v3 dual-infantry 未接 `HeatController`** → `/gimbal/control_bullet_allowance/limited_by_heat` 无生产者，靠 17mm 的兜底常数（100）发弹。
6. **shooting_recorder**：v3 版是**未完成的实验代码**（默认 `friction_wheel_count_ = 6`、写文件到当前目录、声明了多个未用成员/函数），v2 版是干净的成品（2/4 摩擦轮 + 温度记录）。
7. v3 独有：`hero_friction_wheel_controller.cpp`、`hero_heat_controller.cpp`、`putter_controller.cpp`、`pid/friction_wheel_pid_recorder.cpp`。

## 3. 差异清单

### D1 `bullet_feeder_controller_17mm.cpp`（P0，重点）
- **v2 做法**（`v2:95-120`）：
  - `shoot_mode = keyboard.f ? SINGLE : AUTOMATIC`（手动单发）
  - 触发：`bool triggered = mouse.left || switch_left == Switch::DOWN || (switch_right == Switch::UP && *fire_control_);`
  - 输入 `/gimbal/auto_aim/shoot_permit`（可选，`bind_directly(false)` 兜底）
  - 热量接口 `/gimbal/control_bullet_allowance/limited_by_heat` **必选**
  - 有 `rclcpp::Logger logger_;` 成员（构造时 `get_logger()`）
- **v3 做法**（`v3:37-140`）：
  - 删除手动单发：`// @NOTE: Single shoot is only for rune mode, so remove manual switch`；`shoot_mode = ShootMode::AUTOMATIC;`
  - 输入改名：`/auto_aim/should_shoot`、`/auto_aim/single_shoot`（均可选，`before_updating()` 里 `bind_directly(false)`）
  - 触发改写：
    ```cpp
    auto aiming_enable = mouse_->right || (switch_right == Switch::UP);
    auto attack_intent = mouse_->left || (switch_left == Switch::DOWN);
    auto triggered = aiming_enable ? *should_shoot_ : attack_intent;
    ```
  - 单发命中条件新增：`current_single_shoot && current_should_shoot && !last_should_shoot_`；且 `if (current_single_shoot) shoot_mode = ShootMode::SINGLE;`
  - 热量接口改为可选 + `bullet_allowance_default` 兜底（`get_parameter_or("bullet_allowance_default", 100)`，`make_and_bind_directly`）
  - 删除 `logger_` 成员，改用 `get_logger()`
- **影响**：
  1. **单发依赖视觉**（`/auto_aim/single_shoot`），无视觉时无法手动单发
  2. 触发条件把 v2 的 `mouse.left`（直接开火）改成了「有瞄准才用 `should_shoot`」→ 语义变化
  3. 弥补了 v3 dual-infantry 无 `HeatController` 的问题（兜底 100 发）
- **风险**：**高**（P0 机能：开火手感/规则合规）

### D2 `bullet_feeder_controller_42mm.cpp`（P1，双向分叉）
- **v2 做法**：
  - 输入 `/gimbal/bullet_feeder/velocity_filtered`、`/gimbal/bullet_feeder/alive`（**离线即 `reset_all_controls` 并 return**）
  - 输出 `/debug/friction/ready`、`/debug/feeder/ctrl_angle`
  - PID：`velocity_pid_.kp=1.5, ki=0.012, kd=30.0`；`angle_pid_.kp=5.0, ki=0, kd=0`
  - 标定：`compressed_zero_point_ = 1.05`、`angle_per_bullet_ = 2π/5`
  - `overdrive_mode_`/`low_latency_mode_` 成员**存在但从不赋值**（仅 `reset_all_controls()` 置 false）
- **v3 做法**：
  - 输入 `/gimbal/bullet_feeder/velocity`、`/gimbal/bullet_fired`；**无 `/alive`**
  - 无 debug 输出
  - PID：`velocity_pid_.kp=50.0, ki=10.0, kd=0.0, integral_max=60.0, integral_min=0.0`；`angle_pid_.kp=60.0, ki=0, kd=2.0`
  - 标定：`compressed_zero_point_ = 0.58`、`angle_per_bullet_ = 2π/6`
  - `overdrive_mode_ = keyboard.f;`、`if (keyboard.ctrl && !last_keyboard_.r && keyboard.r) low_latency_mode_ = !low_latency_mode_;`
  - 新增 `set_compressing()` / `set_compressed()` 与 `PRELOADED→COMPRESSING→COMPRESSED` 阶段（`angle_pid_.output_max = 0.8`）
- **影响**：**不能用一侧直接覆盖另一侧**。若 v3 mec-hero 需要 v2 的实车手感，需保留 v2 的 PID/标定 + 补回 `/alive` 门控；若采用 v3 的 low-latency 特性则需重新整定
- **风险**：中高（P1）

### D3 `friction_wheel_controller.cpp`（P0）
- **v2 做法**：
  - 输入 `/chassis/operate_mode`（可选）：`if (*operate_mode_ == OperateMode::ASSIST) friction_enabled_ = last_autopilot_enabled_ = true;`
  - autopilot 联动：`if (switch_right == Switch::UP && switch_left != Switch::DOWN) friction_enabled_ = true;`
  - 摩擦轮 `/alive` 门控：`update_friction_status()` 中 `if (!friction_alive_[i].ready() || !*friction_alive_[i]) return;`（不置 `friction_ready_`）
- **v3 做法**：
  - 删除 `operate_mode` 与 autopilot 联动（`switch_left != Switch::DOWN` 条件也去掉）
  - 删除 `/alive` 门控与 `friction_alive_` 数组
  - 新增 `/working_velocity` 输出（`update_friction_working_velocity_outputs()`，供 `deformable_infantry_ui.cpp` 显示）
- **影响**：
  1. v3 摩擦轮 `friction_ready_` 不再受电机离线保护 → 电机离线时可能误开火
  2. `/working_velocity` 需与 UI 消费者配对（v3 的 `deformable_infantry_ui` 用 `/gimbal/left_friction/working_velocity`）
- **风险**：中高（安全相关）

### D4 `heat_controller.cpp`（P0）
- **v2**：`register_output("/gimbal/shooter/heat", shooter_heat_interface_, 0);`（L23）+ 每次 update 写热量
- **v3**：**删除该输出**；`shooter_heat_` 仅内部使用
- **影响**：v2 的 UI（`referee/app/ui/*`）与 `shooting_recorder` 可读实时热量；v3 无此接口 → **v3 无法显示实测热量**（只能显示发弹许可）
- **风险**：中（UI/调试相关）

### D5 v3 dual-infantry 未接 `HeatController`（P0）
- **v2**：`dual-infantry.yaml:22` 有 `HeatController`
- **v3**：`dual-infantry.yaml` **没有** `HeatController` → `/gimbal/control_bullet_allowance/limited_by_heat` 无生产者
- **影响**：只能靠 `BulletFeederController17mm.bullet_allowance_default = 100` 的兜底；**失去真实热量限制**（规则合规风险）
- **风险**：**高**

### D6 `shooting_recorder.cpp`（P1）
- **v2 做法**（成品）：`friction_wheel_count_ = 2`（支持 2/4 轮）；读 `/friction_wheels/temperature`、`/gimbal/*_friction/control_velocity`；输出 `timestamp, initial_speed, v1..vn, temperature`；`log_mode` TRIGGER/TIMING
- **v3 做法**（实验）：`friction_wheel_count_ = 6` 默认；`InputInterface<float> initial_speed_`；成员 `friction_velocities_`/`friction_wheels_velocity_` 声明后未注册；在 `update()` 里 `std::ofstream out_file("shoot_recorder")`（**写到进程当前目录**）且 `analysis1/2/3`、`v`、`aim_velocity` 等调试残留；日志格式改为初速 + 统计量（`velocity_/excellence_rate_/pass_rate_/range_...`）
- **影响**：v3 版不可用于正式数据采集；v2 版对应 mec-hero/dual-infantry 的摩擦轮温度记录
- **风险**：低-中（仅离线分析用途；但 `shoot_recorder` 文件污染工作目录）

### D7 v3 独有发射组件（仅记录）
`HeroFrictionWheelController`（`hero_friction_wheel_controller.cpp`）、`HeroHeatController`、`PutterController`（`putter_controller.cpp`，飞镖/发射机构）、`pid::FrictionWheelPidRecorder`。活跃 config 中均**未被引用**（`grep` 无命中，仅 `plugins.xml` 注册）。
